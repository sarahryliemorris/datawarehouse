# datawarehouse
ETL using DBT and Snowflake to build a data warehouse with dimension and fact tables in a star schema. 

This project was built with team members Archie Frank and Travis Phelps for a Data Warehouse class in my Masters of Data Science.

In this project, we used data for a database "Vbay" to design and create a star schema data warehouse with dimension tables, fact tables, and "one big tables" for Power BI integration.

The actual github documentation for the completion of this project can be found in my team member's repository here: https://github.com/RTFrank/ist722_final_project/tree/main
